# ML Lab Notebooks

Jupyter notebooks for a Machine Learning course.

```
topic_templates/    Reusable per-algorithm templates (01-21.5, plus main.ipynb)
labs/               Final lab notebooks (Lab-1, 2, 4, 5, 7, 12)
assessment_labs/    Final assessment lab notebooks (Assessment-Lab-1 to 5)
```

## Topic templates
Descriptive statistics, linear/logistic regression, KNN, Naive Bayes variants,
decision trees (ID3, CART), perceptrons/MLP, SVM, random forest, K-Means,
K-Modes, agglomerative clustering, PCA, SOM and Q-learning.
